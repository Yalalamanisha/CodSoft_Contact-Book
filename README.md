# Contact Book - Python

## Description
This is a simple Contact Book application developed using Python.
It allows users to add, search, update, view, and delete contacts easily.

---

## Features
- Add new contacts
- View saved contacts
- Search contacts
- Update contacts
- Delete contacts
- Beginner-friendly project

---

## Technologies Used

| Category | Tools / Concepts |
|----------|------------------|
| Programming Language | Python |
| Concepts Used | Dictionary, Loops, Conditions |
| Version Control | Git & GitHub
